# mod-playerbots patches — Demonology rework integration

Versioned patches that teach **mod-playerbots** to play the reworked Demonology spec. They are the
only changes made to the playerbots module; the rework's own side of the bridge lives in this repo
(`src/CommandPool.cpp`, symbol `Demonology_BotLegionStatus`) and ships with the module.

- **Target (pinned):** `mod-playerbots` @ `085e127e38bcc9952338e40e45a8a22472585502`
- **Generated by:** `git diff` from a clean checkout at that commit. Regenerate the same way after
  editing the checkout; do not hand-edit the patch.
- **Applied by:** `install_playerbots.sh` (Phase 5) — `git apply --check` first, refuses on drift.
- **Runtime-gated:** every behavior is gated on rework presence (Command Demon spell `290013`), and
  the cross-module call is a **weak symbol**, so the patched playerbots still compiles and behaves
  byte-for-byte stock on a server without this module.

## Patches

### `0001-demonology-integration.patch`
Non-combat (Phase 3) + combat rotation (Phase 4), one patch. 9 files.

**Non-combat (Phase 3)**
- `WarlockTriggers.{h,cpp}` — `IsReworkDemonology()` gate; `TooManySoulShardsTrigger` no longer
  destroys shards for rework demo bots (Path B); new `LegionPoolNotFullTrigger` (free slot + a shard),
  reading pool state via the weak `Demonology_BotLegionStatus` bridge.
- `GenericWarlockNonCombatStrategy.{h,cpp}` — `SummonLegionAnchorStrategy` (Felguard→Voidwalker→Imp)
  and `LegionPoolStrategy` (fill/refill Imp legionnaires).
- `WarlockActions.h` — `CastSummonImpLegionnaireAction` ("Summon Imp Legionnaire").
- `AiFactory.cpp` — demo non-combat swapped to `legion anchor` + `legion pool` when installed.

Fel Armor preference (Phase 3 item 4) needed no change — the stock armor fall-through already prefers
Fel Armor when known.

**Combat (Phase 4)**
- `WarlockActions.{h,cpp}` — `CastReworkSpellAction` casts BY ID (immune to the Demonic Empowerment /
  47193 name collision): Doombrand 290014 + Wild Imps 290001 on the target, Command Demon 290013 +
  Demonic Empowerment 290000 on self.
- `WarlockTriggers.{h,cpp}` — `DoombrandReadyTrigger`, `CommandDemonWindowTrigger` (brand-align hold),
  `DemonicEmpowermentWindowTrigger`, `WildImpsAffordableTrigger` (shard-reserve gate). Cooldowns via
  `GetSpellCooldownDelay`; brand detected via `target->HasAura(290504, botGUID)`.
- `DemonologyWarlockStrategy.{h,cpp}` — rework branch: rotation Doombrand→Command→Empower→Wild Imps→
  Corruption→Life Tap, fillers Shadow Bolt→Shoot; stock demo path preserved verbatim.
- `AiFactory.cpp` — demo combat drops `meta melee` when installed (demo is ranged now).
- `WarlockAiObjectContext.cpp` — registers all new triggers + actions.

Tuning knobs (defaults in `conf/playerbots-demonology.conf.fragment`): `AiPlayerbot.Demonology.`
`ShardReserve` (2), `CommandBrandAlignWindowMs` (4000), `DoombrandMinTargetHealthPct` (30).
